# Masterclass #1: Bluetooh and Arduino 
 This folder includes files from my exploration from Masterclass #1. In this masterclass I worked togther with Ava to control a motor using BLE bluetooth with our phones, 2 Arduino's communicating with each other, buttons and potentiometers.

 ### Code Files
 - BLUETOOTH_MOTOR includes controlling motor speed from a phone, using the LightBlue app.
 - BLUETOOTH_MOTOR_BUTTON includes turning a motor on and off/ full speed and completely stopped with a button, connected to a different arduino (arduino arduino communication).
 - BLUETOOTH_MOTOR_POTENTIOMETER includes conrolling motor speed with a potentiometer, connected to a different arduino (arduino arduino communication).
